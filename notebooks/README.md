# Running the Colab study

[`AMR_Sentinel_Public.ipynb`](AMR_Sentinel_Public.ipynb) is the source-only notebook. Its saved outputs and Colab runtime metadata were removed for this repository. The original executed notebook and study exports remain local to the author.

Download the national E. coli resistance CSV from the [WHO indicator page](https://data.who.int/indicators/i/918081E/745F475), check the indicator definition and revision shown there, then upload the file in the notebook. The notebook records hashes and emits `amr_project_bundle.zip`. Import that archive in the dashboard or with `python -m src.study --input path/to/amr_project_bundle.zip`.

The reported holdout numbers in the [project report](../reports/MINI_PROJECT_REPORT.md) come from one locally checked run. They are not regenerated by cloning this repository. The uploaded CSV's publication revision was not independently authenticated; inspect the downloaded source before treating the figures as a reproducible WHO release.
